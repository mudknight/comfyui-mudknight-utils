## Dependencies
This node pack optionally requires the following node packs.

### Detailers
Detailer nodes require impact pack nodes for functionality.

- [ComfyUI-Impact-Pack](https://github.com/ltdrdata/ComfyUI-Impact-Pack)
- [ComfyUI-Impact-Subpack](https://github.com/ltdrdata/ComfyUI-Impact-Subpack)

### Simple Prompt
The `Simple Prompt (full-pipe)` node has a `negative_to_negpip` toggle that requires the `CLIP NegPip` module from `ComfyUI-ppm`. You don't need this if you don't want the functionality or don't use the node.

- [ComfyUI-ppm](https://github.com/pamparamm/ComfyUI-ppm)
