weight: 2
---

The Preset Manager is a web interface that lets you define all of your prompt prests, with sections for characters, models, styles, and tags that you can easily use in the `Prompt (full-pipe)` node.

![Preset Manager](/assets/preset-manager.png)

{{< callout type="info" >}}
This was made for SDXL models. Anima requires more specific prompt order and isn't currently supported.
{{< /callout >}}
